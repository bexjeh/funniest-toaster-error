# The Funniest Toaster Error Message

An entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one line, the error message a kitchen toaster shows its owner when something goes wrong. Deadpan, specific, and under 120 characters — a toaster reporting what it found in its crumb tray.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to the current directory when the variable is unset). The program is deterministic: same input, same output, every run.
